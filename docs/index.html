APM / Margin Calculator

Calculate project margin by modelling revenue vs consultant cost

Python 3.9+ CLI Multi-Currency

Overview

The APM Calculator helps analyze project profitability by comparing revenue against consultant costs, supporting different commercial models, currencies, time allocations, and overhead uplift.

APM Formula: APM = 1 - (Loaded Cost / Revenue)

Where: Loaded Cost = Base Cost × (1 + Uplift%)

Features

Revenue Types

Hourly, Monthly, Annual, Fixed Price

Cost Periods

Hourly, Monthly, Annual rates

FTE Scaling

Scales cost only (0-100%)

18 Currencies

USD, EUR, GBP, and more

Usage

Basic Calculation

apm-calc --revenue-type monthly --revenue-amount 15000 --revenue-currency USD \
         --cost-period monthly --cost-amount 8000 --cost-currency USD \
         --allocation 1.0 --uplift 0.25 --reporting-currency USD

Fixed Price Contract

apm-calc --revenue-type fixed_price --revenue-amount 100000 --revenue-currency USD \
         --contract-duration 6 \
         --cost-period monthly --cost-amount 10000 --cost-currency USD \
         --allocation 1.0 --uplift 0.25 --reporting-currency USD

Cross-Currency Calculation

apm-calc --revenue-type hourly --revenue-amount 150 --revenue-currency EUR \
         --cost-period hourly --cost-amount 75 --cost-currency GBP \
         --allocation 0.5 --uplift 0.20 --reporting-currency USD

CLI Options

Option Description
--revenue-type, -rt hourly, monthly, annual, fixed_price
--revenue-amount, -ra Revenue amount
--revenue-currency, -rc Revenue currency (e.g., USD, EUR)
--contract-duration, -cd Contract duration in months (for fixed_price)
--cost-period, -cp hourly, monthly, annual
--cost-amount, -ca Cost rate amount
--cost-currency, -cc Cost currency
--allocation, -a FTE allocation (0-1, default: 1.0)
--uplift, -u Overhead/uplift percentage (e.g., 0.25 for 25%)
--reporting-currency, -o Output currency
--hours-per-month Hours per month (default: 160)
--json, -j Output as JSON
--interactive, -i Interactive mode
--list-currencies List supported currencies
--list-rates List exchange rates

Supported Currencies

USD, EUR, GBP, CHF, AUD, CAD, JPY, CNY, INR, SGD, HKD, NZD, SEK, NOK, DKK, ZAR, BRL, MXN

Exchange rates are static and can be customized programmatically.

Python API

from apm_calculator import APMCalculator

calculator = APMCalculator()

result = calculator.calculate(
    revenue_type="monthly",
    revenue_amount=15000,
    revenue_currency="USD",
    cost_rate_period="monthly",
    cost_amount=8000,
    cost_currency="USD",
    allocation_fte=1.0,
    uplift_percent=0.25,
    reporting_currency="USD",
)

print(f"APM: {result.apm_monthly:.2%}")  # APM: 33.33%
print(result.to_dict())  # Get as dictionary
